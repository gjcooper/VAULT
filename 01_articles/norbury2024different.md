## My Thoughts

An article that provides some impulse for the [[Hypatia Health Phase 2]] project as it tests the applicability of a cognitive model for assessing the mechanism behind a behavioural therapy/intervention. Of particular interest is the [[Effort-Reward task]] outlined in this paper (from [[berwian2020computational]]). This effort/reward task and associated model could provide a possible extension to our projects model suite.

To add to the Hypatia project we would need a new task type (effort/reward) plus a new model (effort sensitivity). This bears some thinking about. A lot to borrow/steal here about the model recovery, [[simulation-based calibration]] and more.
